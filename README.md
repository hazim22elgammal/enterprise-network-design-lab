# Enterprise Network Design Lab

## 📌 Overview
This project simulates an enterprise-level network using Cisco Packet Tracer, focusing on high availability, security, and performance.

## 🏗️ Network Design
- Core Layer
- Distribution Layer
- Access Layer

## ⚙️ Technologies Used
- OSPF
- VLANs
- Inter-VLAN Routing
- HSRP
- EtherChannel
- NAT (PAT)
- ACL

## 🛡️ Security
- Port Security
- ACL
- VLAN isolation for unused ports

## 🔁 Redundancy
- HSRP (Gateway redundancy)
- EtherChannel
- Failover design

## 📡 Services
- DHCP (Primary & Backup)
- DNS
- IP Helper

## 🧪 Testing
- Failover testing between routers
- DHCP backup activation
- ACL traffic filtering validation
